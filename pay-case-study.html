01

Objective

Design a high-converting, visually compelling, and interactive landing page for a fintech startup's payment gateway product — similar in category to Razorpay, Stripe, or Cashfree. The brief called for strong UI/UX fundamentals paired with infographic-style animation and microinteractions to boost engagement and clarity.

04

Visual System

Color Palette
#1E4AD5

The blue speaks to trust, security, stability.

Why fintech companies use blue:

  • Blue feels safe → good for payments
  • Blue conveys seriousness & professionalism
  • Encourages users to enter card details without fear
  • Works well for technical content
#FFFFFF

The white speaks to simplicity, cleanliness.

  • Helps in maintaining visual clarity
  • Makes the UI feel light and breathable
  • Perfect for modern, minimal layouts
Other
Typography
Aa
  • Friendly — soft rounded terminals make it look welcoming and cheerful.
  • Modern — geometric shapes give a clean, fresh, contemporary feel.
  • Minimal & Light — perfect for brands that want a simple, positive, optimistic visual style.

05

Interface

Every section of the page redesigned against a specific weakness found in the competitor audit — issues in, improvements out, impact measured.

Hero Section
Stronger first impression

Improvements
  • Clear headline + subheadline
  • Proper CTA hierarchy (primary + secondary)
  • More whitespace → reduces cognitive load
  • Modern fintech illustration
  • Proven left-text + right-visual format
  • Animated icons for engagement
Impact
  • Faster understanding in the first 3 seconds
  • Higher chances of conversion
  • Friendly brand personality thanks to Quicksand

Why Choose Us
Better feature communication

Earlier Issues
  • Generic feature lists
  • No visual separation
  • Harder to scan quickly
Improvements
  • Consistent icon style
  • Four structured feature blocks
  • Short, benefit-focused titles
  • Clean typography + animated icons
Impact
  • 40–60% improvement in scannability
  • Users understand benefits much faster

Developer Section
Major UX upgrade

Improvements
  • Dark-mode code block (industry standard)
  • Simple API explanation
  • Tab-based code viewer (Node.js, Python, PHP, React Native)
  • Clear "View Documentation" CTA
  • Typing animation for engagement

Features Section
More readable & structured

Improvements
  • Clean vertical layout
  • Left-aligned text for better readability
  • Animation shows the flow of the core payment gateway offering
  • Short, bullet-style descriptions

Social Proof
Stronger trust & credibility

Improvements
  • Simple card structure
  • Grayscale photos for a premium feel
  • Vertical auto-scroll; hover reveals more detail
  • Clean attribution style
  • "Trusted by 8,00,000+" placed strategically

Final CTA
Better conversion flow

Improvements
  • Clear conversion message
  • Dual CTA structure — Talk to Sales + Start Now
  • Supporting fintech animated illustration
06

Heatmap Analysis

Heatmap analysis helps us understand how real users move, click, scroll, and interact with a landing page. It visually highlights high- and low-attention areas so the layout can be redesigned for better conversion.

Reading 01
CTA pair pulls the strongest heat
The hero's Get Started / View API Docs pairing shows the densest red concentration on the page — the dual-CTA hierarchy is doing its job.
Reading 02
Icon row draws the eye first
Attention lands on the "Why Choose Us" icons before the copy — validating the consistent icon system as the section's entry point.
Reading 03
Decorative graphic competes for focus
The abstract node graphic beside Features pulls a hot zone of its own — a sign it's competing with the feature list rather than supporting it.
